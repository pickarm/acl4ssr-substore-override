连接你的 GitHub

点击下方按钮，用你自己的 GitHub 账号登录。首次使用需将 Rule Desk 应用安装到指定规则仓库。

登录令牌仅保留在当前页面内存中，刷新后再次点击 GitHub 登录即可。以下访问令牌方式作为备用。

  1. 打开 GitHub 令牌设置，创建 Fine-grained token。
  2. Repository access 只选 acl4ssr-substore-override。
  3. Repository permissions 中将 Contents 设为 Read and write，设置有效期并生成。
  4. 把令牌填在下方，仅用于直接访问 GitHub API。

令牌仅在当前页面内存中使用，刷新页面后需要重新连接。不要发到聊天或提交到仓库。

也可用 GitHub 自带编辑器修改规则源（提交后由生成任务更新订阅文件）。

批量导入

支持普通域名、DOMAIN、DOMAIN-SUFFIX、DOMAIN-KEYWORD、IP-CIDR、IP-CIDR6。重复或冲突时停止导入。也可粘贴本工具导出的 JSON 备份。
